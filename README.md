# Einmal preview

A prototype that colours German nouns by gender (der = blue, die = red, das = green; grey = not sure).
Pasted text is processed in the browser and never leaves the device.

`forms.json` and `words.txt` are derived from English Wiktionary (https://en.wiktionary.org) via Wiktextract (https://github.com/tatuylonen/wiktextract) and are licensed under CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/).
